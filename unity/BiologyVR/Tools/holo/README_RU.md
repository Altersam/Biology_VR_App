# Голограмма пациента и приборы (Biology VR 2, 03.11)

Скрипты Blender (запуск: `blender -b -P patient.py` или `python3 patient.py` с модулем bpy), рядом сохраняют .blend и .fbx.

- `patient.py` → `patient.blend`, `Patient.fbx`: фигура человека 1,78 м (оболочка тела — скелет-модификатор + сглаживание), артерии и вены трубками (UV.x = метры от сердца — для бегущих импульсов в `BVR2_HoloFlow`), сердце (центр объекта — в центре сердца, чтобы биться на месте), лёгкие, метка точки входа на предплечье. Лицом к −Y, ноги на z = 0.
- `tools.py` → `tools.blend`, `Tools.fbx`: сканер и BioTool. Каждая деталь — свой объект `<Прибор>_<Деталь>_<Материал>` (Body / Dark / Glow / Glass), центр — в центре детали (кольца и катушки крутятся вокруг своей оси). Приборы смотрят в −Y, начало координат — точка хвата.
- `rpat.py`, `rtools.py` — быстрые рендеры для проверки.

Копии FBX — `Assets/BiologyVR/BiologyVR2/Art/Holo/`. В Unity их разбирает `Editor/Bvr2HoloFx.cs` (материалы по суффиксу имени, ориентация и размер по корпусу и линзе). Исходники .blend — `3д/Голограмма и приборы/`.
