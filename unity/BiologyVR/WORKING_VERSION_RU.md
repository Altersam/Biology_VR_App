Unity Hub → Add project → выбрать `bio_v0.2` → Unity 6000.1.9f1.
После импорта открыть master scene и нажать Play. Кликнуть в Game.

ПКМ — осмотр; Z — увеличение; G — альтернативный захват; → — продолжить.
