## Эта версия — Unity, WebGL, PICO 4 и Meta Quest / Oculus APK 0.7.0

- Coral V6: более гладкий, кораллово-красный сосуд, крупные мягкие endothelial cells.
- Контрастные красные RBC, холодные светлые WBC и тёплые yellow/orange platelets.
- Один основной свет, лёгкий градиент глубины и визуальная пульсация 1,2% / 72 BPM.
- Без постоянного cyan-декора V5 и per-cell realtime displacement.
- Новая компактная Unity-геометрия Scanner и BioTool, общая cream/graphite/cyan/amber система.
- Краткая теория/задача и отдельная прокручиваемая справка; монитор из пяти карточек.
- Непрерывный случайный кровоток впереди/позади и во всех трёх ветвях: общий лёгкий пул 360, мобильный бюджет 180, восемь ограниченных интерактивных представителей.
- Бляшка: 30 начальных элементов + случайный приток 1–2 липидов в секунду; стрельба по летящим и прикреплённым элементам, окклюзия/локальный повтор.
- Шесть самостоятельных газовых эмболов: каждый надо захватить и удерживаемым полем перенести в ловушку; выполненные размещения сохраняются при отпускании.
- Правые **A/B** — режимы BioTool вперёд/назад, **левая Y** — Continue. Импульс, захват, анимации корпуса и фиксация объекта имеют разные эффекты.
- Сохранены текущий маршрут, остальные взаимодействия, InputActions и состояния мира.
- **Первый этап — свободное исследование:** любой объект можно выбрать первым.
  Эритроцит, лейкоцит, фагоцит, тромбоцит и плазма имеют независимые статусы.
  Выбирается конкретная клетка из общего пула; фагоцит — функциональный архетип лейкоцита.
  Пустые RBC и RBC с O₂/CO₂ движутся в общем потоке; учебный Hb несёт связанный
  гем/Fe²⁺. Автоматическое раскрытие молекулярной схемы при захвате отключено.
  Короткие страницы и реплики профессора появляются
  из действия; повторы не дают новый зачёт. Continue открывается после 5/5 без auto-transition.
- **Захват клетки:** BioTool ПРИТЯЖЕНИЕ и правый Trigger. Scanner — левый Trigger.
  Grip не является способом взять клетку потока; отпускание поля возвращает её в кровь.
- **Врождённая защита:** один медленный первый вирус; захват фагоцита → Scanner →
  АКТИВАЦИЯ → РЕВЕРС → прицелиться → отпустить Trigger. Запускается сама клетка.
  Первый вирус требует трёх контактов свежих фагоцитов; их доля в потоке увеличена.
- **Scenes09/15:** та же манипуляция клетками внутри живого кровотока, без повторного
  tutorial. В Scene09 повышенная Viral Load удерживает этап открытым до её снятия.
- **Сосудистое поле:** Scanner стенки → расширение/критическое изменение →
  безопасный диаметр → повторный Scanner. AR-точки и карточки гипотез убраны;
  формулы слева, динамические значения справа, критическое состояние сигнализируется.
- **Бляшка:** повышение давления перед участком, замедление/скопление потока;
  скрытый refill не переносит кровь через препятствие. Улучшена анимация импульса.
- **Эмболы:** случайный дрейф; потеря наведения останавливает притяжение и устойчивость,
  возврат прицела возобновляет поле. Захват пузырей только курком.
- **WALL_A:** продольный разрыв; утечка отводит существующие клетки основного пула.
  Удерживаемый CAPTURE доставляет тромбоциты, адгезия автоматическая. 11/11 — первичная
  пробка с остаточной утечкой; карточки активации/агрегации/тромбин-фибрина запускают постепенную стабилизацию.
- Насыщенный фон продолжается во всех артериальных сценах, включая финальные;
  UI больше не отключает весь ввод, режимы анимированы и направляющие сохраняются.
- Экраны развёрнуты к центру: Bold/outline, плотный контрастный фон, raster 5.

## Управление ПК

Мышь — указатель; F удерживать — Scanner; E — BioTool/поле; ПКМ — осмотр;
колесо — глубина притяжения или диаметр при удерживаемом сосудистом поле;
ЛКМ — физические карточки; → — продолжить завершённый этап.
C — смена режима BioTool; Tab / «Подробнее» — полная теория; колесо над ней — скролл.
Первый этап: захватите носитель через E в ПРИТЯЖЕНИИ, изучите F и отпустите E.
«Ещё →» раскрывает следующую короткую страницу; повторное чтение сохраняет прогресс.
Газы и железо доступны на носителях; «Ещё →» открывает следующую страницу теории.
Фагоцит: E/ПРИТЯЖЕНИЕ → F → E/АКТИВАЦИЯ → E/РЕВЕРС → навести → отпустить E.

В Scene07 удерживайте E, направьте указатель к стабилизационному кольцу и
колесом подберите глубину. Интерфейс использует встроенный Inter с кириллицей.
Повторите размещение для всех шести пузырьков. Scene06: E — импульс, удержание — очередь;
очистите исходную массу и прилетающие липиды до перекрытия просвета.
Scene05: F — стенка; E/СОСУДИСТОЕ ПОЛЕ и колесо — диаметр. Scene12: удерживать CAPTURE, подвести
тромбоцит к повреждению до автоматической адгезии, затем собрать цепочку стабилизации.

## Управление VR

Левый Trigger — Scanner, правый Trigger — выбранное действие BioTool.
Правая A — следующий режим, B — предыдущий; левая Y — продолжить завершённый этап.
Захват клетки — только BioTool ПРИТЯЖЕНИЕ + правый Trigger; Grip остаётся для физических карточек.
Правый стик над справкой — скролл. Фагоцит: захват → Scanner → АКТИВАЦИЯ → РЕВЕРС → отпускание.

## Обновление на GitHub

В GitHub Desktop выбрать **Biology_VR_App**, проверить Changes, Summary:
**Update player feedback rework and headset builds 0.7.0**, затем **Commit to main → Push origin**.
Повторный Publish repository не нужен. GitHub Pages: main → /(root).

PICO и Meta Quest APK публикуются в release **v0.7.0** из проверенных файлов в ReleaseFiles.
Эти файлы не входят в обычный commit. Все файлы `play/` хранятся обычным Git,
Git LFS применяется только к Unity-ресурсам вложенной .gitattributes.
