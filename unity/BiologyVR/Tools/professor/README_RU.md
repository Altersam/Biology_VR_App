# Профессор: модель (волосы, говорящий рот)

Исходник — `3д/Профессор/professor_v10.blend` (03.11; до того — `professor_v9/v8/v4.blend`) (до проверки тела — `professor_v3_talking.blend`) (собран из частей «Профессор по частям» и `голова_эмоции.blend`). Экспорт → `Assets/BiologyVR/BiologyVR2/Art/Professor/Professor.fbx`.

Скрипты (Blender 4.2+ / модуль `bpy`, запуск `python скрипт.py` из папки с .blend):

- `hairfix.py` — `professor_relaxed.blend` → `professor_v2.blend`: волосяная «шапка» по черепу (закрывает виски, бакенбарды до бороды, огибает уши, кончается на затылке; текстура `Prof_HairCap_BaseColor.png`) + прежний чуб ниже и уже.
- `face_mouth.py` — `professor_v2.blend` → `professor_v3.blend`: рот разрезан по линии губ, внутри полость и два ряда зубов (в той же сетке головы: материалы `Prof_Head`, `Prof_Mouth`, `Prof_Teeth`); ключи формы `MouthOpen` (челюсть поворачивается в височно-нижнечелюстном суставе), `MouthO`, `MouthWide` на голове, `MouthOpen` на бороде и усах.
- `body_fix.py` — `professor_v3.blend` → `professor_v4.blend`: кисти вставлены в манжеты и продолжают предплечье (опорная точка — запястье), рубашка убрана под халат там, где проступала (спина, плечи; спереди воротник рубашки остаётся), основание шеи сзади уходит в воротник без «тарелки», значения ключей формы сброшены.
- `export_fbx.py` — `professor_v4.blend` → `unity/Professor.fbx`.
- `rmouth.py` — проверочные рендеры рта: `python rmouth.py -- professor_v3.blend m "" "MouthOpen=1" "MouthO=1,MouthOpen=0.35"`.

Кисти без текстуры: цвет кожи задаёт билдер (тон лица). В Unity сетки с ключами формы получают SkinnedMeshRenderer в билдере сцены; рот ведёт `Bvr2Professor` по кривым из `voice_manifest.json` (см. `Tools/voice`).

## 02.11 — шея (professor_v5)

`neck_fix.py`: голова с волосами и бородой ниже на 1,2 см; кожаный обрубок шеи у рубашки перекрашен в ткань и прижат к шее (стоечка воротника); лоскут горла ниже воротника удалён. Затем `export_fbx.py` (из professor_v5.blend) → `Art/Professor/Professor.fbx`. В Unity голова поворачивается вокруг основания шеи (`HeadPivot` ставит билдер).

## 03.11 — шея в одежде, ремешок амулета, волосы (professor_v8)

`prof_v8.py`: `professor_v5.blend` → `professor_v8.blend` + текстуры в `tex_v8/` (`Prof_HairLocks`, `Prof_HairCap`, `Prof_Collar`, `Prof_ShirtCollar`, `Prof_Strap`, `Prof_Hair` `_BaseColor.png` → `Art/Professor/Textures/`).
Слои вокруг шеи: шея (у основания толще) → `ShirtCollar` (стойка с отложным краем, спереди открытый вырез) → `Collar` (лаймовый воротник халата: сзади стоит, книзу ложится на халат, концы уходят в лацканы) → `Strap` (кожаный ремешок амулета вокруг шеи поверх воротника; U-петля медальона выше z 1,335 удалена). Воротники рассчитаны на поворот головы на ±48° вокруг основания шеи.
Волосы: гладкие острова затылка удалены, тонкая `HairCap` по черепу, `HairLocks` — 48 сужающихся прядей в два слоя с нормалями, сглаженными по форме головы.
Затем `export_fbx.py` (из professor_v8.blend) → `unity/Professor.fbx` → `Art/Professor/Professor.fbx`; Build Scene.
Проверка: `rpose.py -- professor_v8.blend tag [yaw pitch]` + `sheet.py tag out.jpg` (8 ракурсов на уровне глаз игрока), в Unity — `Bvr2LabProbe.ProfShots("file.jpg", yaw, pitch)` (поворот вокруг профессора, кадры в `ClaudeBridge/shots/`).

## 03.11 (позже) — доводка: круглая шея, застёгнутый воротник (professor_v9)

`prof_v9.py` (развитие `prof_v8.py`): `professor_v5.blend` → `professor_v9.blend` + `tex_v9/`.
- шея ниже челюсти круглая вокруг оси поворота (`R_neck`, плавный переход к исходной форме над воротниками); внутренние вершины обрубка масштабируются вместе со стенкой, ничего не торчит за круг;
- `ShirtCollar` — замкнутое кольцо (воротник застёгнут, уголки ±12°, дно), внутренняя поверхность: шея + 2,5 мм + запас под кивок;
- старые куски рубашки у шеи убраны или подоткнуты под стойку, лацканы халата уложены на воротник рубашки, лаймовые обрывки старого воротника на плечах перекрашены в белый (UV на белый тексель);
- ремешок: «выталкивание» из одежды размазано вдоль пути (max → среднее по окну), нормали сглажены;
- волосы: убраны низкие боковые острова чуба у висков, добавлены бакенбарды, край `HairCap` прижат к линии `hairline()`;
- `Prof_Hair_BaseColor_orig.png` рядом со скриптом — текстура чуба ДО осветления (скрипт осветляет её сам).
В Unity: `BVR2/Hologram` получил `_Cull` (билдер ставит Off для `Hair`, `Beard`, `Mustache`); проверка — `Bvr2LabProbe.ProfShots("file.jpg", yaw, pitch, dist, aimY, solid)`.

## 03.11 (вечер) — короче шея (professor_v10)

`prof_v10.py` = `prof_v9.py` + сдвиг головы `D2 = 0.055` (было 0.040): голова (Head, Hair, HairCap, Glasses, Beard, Mustache) опускается на 5,5 см, все константы, привязанные к голове (круглая шея `R_neck`/`round_w`, верх воротников, зазор под кивок, линия волос `H`, центр черепа `C`, уши, бакенбарды), сдвинуты на `D2`; ремешок — на `0.8·D2`. Тело (рубашка, халат, медальон) не двигается. Низ шеи сужается в тело (не вылезает при повороте), под отворотом воротника халата — подворот до халата, белая ткань под воротником убрана под него.
